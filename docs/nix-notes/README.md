# Nix Notes

本目录用于记录学习和总结的 Nix 相关知识:排查经验、常用命令、踩坑记录等。

`docs/` 目录本身用途更广(项目文档、设计说明等),Nix 相关的个人学习笔记统一放这里,便于检索和回忆。

## 如何添加新笔记

1. 内容聚焦单一主题,一个主题一个文件
2. 开头用一两句话说明适用场景
3. 命令给出可直接复制的完整形式,并在文末列出"常见坑"
4. 在下方索引表格中追加一行
